The word I would delete from the dictionary forever is **Delete** — the only deletion that deletes itself. Erase "delete" and the dictionary can never again describe what happened to it: the entry, the act and the punchline are one and the same word. It lands the instant you read it, needs no caption, and no other pick can steal the trick.

## Run it

```sh
python3 main.py
```

This writes the single word `Delete` (6 characters, no trailing newline) to `/output/entry.txt`, honouring the `MAKEFUN_OUTPUT_DIR` environment variable when set. Pure Python standard library, no network, no files read from outside the repo.
